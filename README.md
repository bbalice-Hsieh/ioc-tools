# IOC Tools

Small tools and utilities for IOC extraction, threat intelligence, and incident response.

## Overview

This repository contains lightweight defensive cybersecurity tools and scripts used during malware analysis, threat intelligence, and DFIR investigations.

## Planned Tools

- IOC Extractor
- SHA256 Hash Checker
- Domain Parser
- URL Normalizer
- IP Address Validator
- DNS Lookup Helper
- WHOIS Helper

## Purpose

The goal of this repository is to provide lightweight utilities that assist with IOC collection, validation, malware analysis, and incident response workflows.

## Disclaimer

This repository is intended solely for defensive security research and educational purposes. It does not contain offensive tools, malware samples, or content intended to facilitate unauthorized activities.
